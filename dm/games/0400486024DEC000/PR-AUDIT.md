## Cache and validation

The offline Metal libraries are stored in `shader.noindex/cache/b-<chain>.img`, and the content-addressed compile cache is `shader.noindex/cache/cas.db`. The migration from `shader/` uses a rename; it does not recreate the caches. Keep the build folder and these two files. Changing the translator, shader chain, inputs or compiler may require revalidation or rebuilding; no stale output is force-accepted. Markdown note changes no longer invalidate the shader step; a regression test verifies that real shader-table changes still do.

The BAHS discovery correction removes a metadata false positive, not a supported shader. The remaining shader identities and cache reuse are checked against the regenerated package. Only Ocarina has a prepared local Mac build, so other games are unchecked. See the game note for the final validation outcome.

Front-ends: interface: the shader build folder is now `shader.noindex/`; tools accept existing `shader/` builds and migrate the folder without discarding its caches.
