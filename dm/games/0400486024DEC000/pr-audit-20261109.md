# Ocarina PR integration, 2026-11-09

Target: M2 Max MacBook Pro, 96 GB RAM. Baseline: `c52cf70a`.

The GitHub open-PR search returned 100 matches with the query `is:pr state:open ocarina` and a limit of 100. This audit covers those exact snapshots; the higher-limit API request was blocked by session networking, so this is not a claim that GitHub has only 100 matches. Every imported commit retains its source SHA in its cherry-pick message.

## Result

Imported 32 distinct PRs. Existing fork fixes remain. The default is still 60 fps, with threaded encoding, late-frame holds disabled and game-barrier compute overlap enabled. MetalFX upscaling, reduced render scale, movie-enhancement bypass and pool precreation remain player choices. No claim of measured M2 Max speedup is made.

The translator combines range resolves (#1752), bind-time pointer sites (#1585), and current upstream vector loads, including miss zeroing and vector-group boundaries. Its rebuilt AnyCPU DLLs, tool lock and chain header are committed together; the universal launcher is preserved. The archive capture lock now covers object, mesh and fragment stages as well as ordinary vertex/fragment pipelines.

## Validation

- Mac host builds for `GAME=0400486024DEC000`; translator builds with zero warnings/errors.
- 130 focused profile/settings/docs/chain/save/profiling/build-progress/offline-pipeline tests pass under Python 3.13; the iOS-only real-library case is excluded.
- 123 focused shader tests run: 120 pass and 3 optional tests skip; GPU execution and dual-platform compilation were excluded from that focused run. Six translator-enabled raw scalar/vector/range tests pass.
- Full graphics suite builds its binaries, then stops at `t_addr_known`: this sandbox exposes no Metal device. Full shader-suite attempts likewise encounter unavailable GPU execution and the iOS metallib tool; these are not runtime passes.
- Full host suite stops at an unavailable AudioUnit device. Focused input-stream tests pass with fake capture, device changes, WAV feed and Bluetooth-device selection; reflection passes 52 checks (2 missing-sample checks skipped), frame-step passes 78 checks, and pipeline-key round trips pass. The broader Mac-app packaging test encounters iconutil rejecting its synthetic iconset. Python lint cannot complete because the configured venv has no pyright.
- Five-game quick regression was attempted for Ocarina (mesh/compute/frame step), Breath of the Wild and Tears of the Kingdom (NVN and whole-vsync stubs), Pokémon Scarlet (ordinary NVN), and Hades (host loading). It stops at discovery: no qualifying Mac builds found under /Users/aeonitis/Games/Switch2. Gameplay, full game shader-library rebuild, full multi-game regression and M2 Max performance measurements remain open. Existing installed game libraries belong to the previous chain and must be rebuilt before using this host.
